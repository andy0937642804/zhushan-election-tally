# 竹山鎮鎮民代表第一選區計票系統

Static website prepared for GitHub Pages.

## Publish
1. Create a GitHub repository (e.g. `zhushan-election-tally`) and upload these files to the `main` branch.
2. In the repository Settings → Pages, select **GitHub Actions** as the deployment source.
3. Push/commit the workflow and files. The workflow deploys automatically.

The site is a local-browser tally prototype. It does not synchronize votes across multiple devices or provide cloud storage.
